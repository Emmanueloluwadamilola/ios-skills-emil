# ios-skills-emil

Emil Kowalski animation and UI-design skills.

> **Curated mirror** of [https://github.com/emilkowalski/skills](https://github.com/emilkowalski/skills) by **Emil Kowalski**. All credit to the original
> author. See [ATTRIBUTION.md](./ATTRIBUTION.md). Contains **18** skill(s).

## Install (Claude Code)

```bash
claude plugin marketplace add Emmanueloluwadamilola/ios-skills-emil
claude plugin install ios-skills-emil@ios-skills-emil
```

## Install (any agent)

```bash
git clone https://github.com/Emmanueloluwadamilola/ios-skills-emil.git
cp -R ios-skills-emil/plugins/ios-skills-emil/skills/* ~/.agents/skills/
```

Each folder under `plugins/ios-skills-emil/skills/` is a self-contained skill you can also
install individually.
